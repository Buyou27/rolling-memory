# 安全

**[English](../../SECURITY.md) · [简体中文](SECURITY.md)**

## 受支持版本

安全修复应用于最新的公开发布版本。旧版本按尽力而为原则提供支持；报告前请先在最新版本上复现。

## 报告

请私下向首席架构师与维护者报告疑似漏洞（**Albert**，`support@psychologylake.org.cn`，Rocareer 与
Rolling Memory 组织），不要在公开 issue 中披露漏洞细节。公共 GitHub 仓库上线后，GitHub 私有漏洞
报告是首选渠道，邮件为后备渠道。报告请包含版本、最小复现，以及是否涉及敏感数据或本地模式出网。
我们按尽力而为原则确认报告，并在修复可用后协调披露。

## 与安全相关的不变量

- 本产品不构建任何记忆面网络传输：召回、存储与结晶全部在本地金库完成。对外请求仅三类：你自行配置的评测大模型端点、可选的上游基准语料下载，以及可选的更新检查；试图把记忆面指向远端服务的环境变量或配置不会有任何作用。以申请制提供的独立云端记忆服务（端到端密文设计）属于本客户端与本仓库之外的另一独立安全面。
- 保护本地存储、备份以及与外部服务共享的数据中的敏感信息。
- API Key 从环境变量或 `0600` 文件读取，不存入数据库或配置文件。
- SQLite 数据库仅存于本地且未加密；设备与他人共享时请使用全盘加密或加密卷。
