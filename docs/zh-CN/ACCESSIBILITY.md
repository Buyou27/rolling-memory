# 无障碍

**[English](../../ACCESSIBILITY.md) · [简体中文](ACCESSIBILITY.md)**

无障碍是质量的一部分：我们可控界面中的一道障碍是缺陷，而不是特殊请求。本页说明本项目提供的界面、
目前支持的环境、已经知悉的局限，以及如何报告无障碍障碍。

## 界面

Rolling Memory 有四个面向用户的界面：

- **命令行（`rolling-memory` / `rmem`）**——纯文本输入输出；结果以文本标题分节，
  可配合屏幕阅读器使用，也可通过管道传给其他工具。
- **MCP 工具（`recall`）**——返回结构化文本；呈现方式取决于你所用的宿主
  （编辑器、对话界面或终端）。
- **Web 控制台（`rolling-memory panel`）**——基于标准、可键盘操作的组件库构建；
  布局在浏览器缩放与系统文字缩放（text scaling）下均可使用。
- **桌面启动器**——标准的平台菜单窗口，用于打开 Web 控制台。

文档以英文与简体中文一对一镜像维护。

## 支持的环境

- 桌面浏览器当前版本：Chrome、Edge、Firefox 与 Safari。
- 命令行与控制台支持 macOS、Windows 与 Linux；桌面安装包面向 macOS 与 Windows。
- 命令行可用于任何终端模拟器，包括配合屏幕阅读器使用的场景。

## 已知局限

- 尚未进行正式的第三方无障碍审计。
- 控制台的个别视图以视觉呈现为主——基准图表与记忆图谱以指针操作为主，
  尚无完整的文本替代方案；相关数字在相邻面板与表格中同时以文本形式给出。
- 控制台面向桌面视口；小屏使用按尽力而为原则支持。
- 系统性的辅助技术测试尚未纳入每次发布；报告是获得修复最快的途径。

## 报告无障碍障碍

- 发送邮件至 `support@psychologylake.org.cn`，标题前缀 `[accessibility]`；或在
  <https://github.com/rocareer/rolling-memory/issues> 提交议题。
- 请注明界面（命令行 / MCP / 控制台 / 桌面应用 / 文档）、操作系统与辅助技术
  （屏幕阅读器、放大镜、语音控制）、你的操作步骤，以及预期与实际结果。
- 请移除附件中的金库内容、密钥与个人数据。

报告的受理与处理与其他议题一样按尽力而为原则进行；响应预期见 [SUPPORT.md](SUPPORT.md)。
