# 行为准则

**[English](../../CODE_OF_CONDUCT.md) · [简体中文](CODE_OF_CONDUCT.md)**

## 我们的承诺

作为社区成员、贡献者与维护者，我们承诺：不论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、
经验水平、教育程度、社会经济状况、国籍、外貌、种族、种姓、肤色、宗教信仰、性取向与性别认同如何，
参与本社区对每个人都是免于骚扰的体验。

我们承诺以有助于建设开放、友善、多元、包容且健康社区的方式行动与互动。

## 我们的标准

有助于为本社区营造积极环境的行为包括：

* 对他人展现共情与善意
* 尊重不同的意见、观点与经历
* 给予并得体地接受建设性反馈
* 为自己的错误承担责任、向受影响者致歉，并从中吸取经验
* 关注的不仅是个人的得失，更是整个社区的福祉

不可接受的行为包括：

* 使用性化语言或带有性意味的图像，以及任何形式的性关注或性示好
* 挑衅、侮辱或贬损性评论，以及人身攻击或政治攻击
* 公开或私下的骚扰
* 未经明确许可公布他人的私人信息，如住址或电子邮箱
* 其他在职业场合中可被合理视为不当的行为

## 维护责任

社区维护者有责任阐明并执行可接受行为的标准，并对任何其认为不当、威胁、冒犯或有害的行为，采取适当且公平的纠正措施。

社区维护者有权并有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、议题及其他贡献，
并在适当时候说明其管理决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表本社区的情形。
代表本社区的示例包括：使用官方电子邮箱地址、通过官方社交媒体账号发帖，或在线上或线下活动中担任指定代表。

## 执行

如遇辱骂、骚扰或其他不可接受的行为，可通过 `support@psychologylake.org.cn`
向负责执行的社区维护者报告。所有投诉都将得到及时、公正的审查与调查。

所有社区维护者都有义务尊重事件报告者的隐私与安全。

如系安全漏洞，请改按 [SECURITY.md](SECURITY.md) 处理，不要在公开议题中披露漏洞细节。

## 执行准则

社区维护者在决定其认为违反本行为准则的行为的后果时，将遵循以下社区影响分级准则：

### 1. 纠正

**社区影响**：使用了不当言辞，或其他被社区视为不专业或不受欢迎的行为。

**后果**：由社区维护者发出一份私下书面警告，说明违规行为的性质及为何不当；可能要求公开道歉。

### 2. 警告

**社区影响**：由单一事件或一系列行为构成的违规。

**后果**：发出警告，并附带对持续行为的后果。在指定期限内，不得与相关人员互动，包括不得主动接触执行本行为准则的人员；
这一限制同时覆盖社区空间与社交媒体等外部渠道。违反上述条款可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定期限内，禁止以任何形式与本社区互动或公开交流。在此期间，不得与相关人员有任何公开或私下互动，
包括不得主动接触执行本行为准则的人员。违反上述条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：呈现出反复违反社区标准的行为模式，包括持续的不当行为、对个人的骚扰，或对特定群体的攻击或贬损。

**后果**：永久禁止在本社区进行任何形式的公开互动。
