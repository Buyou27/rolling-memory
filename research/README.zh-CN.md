# 研究目录

**[简体中文](README.zh-CN.md) · [English](README.md)**

这里是给**研究者**（而不是给接线到智能体的人）准备的材料：可复现的分析代码、统计笔记，以及把本地金库变成数据的小工具。

本目录不参与运行时，任何子目录都不被产品依赖。每个子目录自带依赖说明，可以单独拿走。

| 目录 | 语言 | 内容 |
| :--- | :--- | :--- |
| [r/](r/) | R | 命令行薄封装（`rmemory.R`）、端到端演示，以及占据天数零分布尾界的 base R 复算 |

## 约定

- **默认只读**：分析代码不应改写金库；`r/demo.R` 建自己的临时库，不碰你的真实数据。
- **一条命令可复现**：每个目录附一个入口脚本，先打印它检查了什么，再给结论；评审者不必先读源码。
- **不依赖内部构建**：需要私有开发树才能跑起来的样例，不放这里。

新增其它语言的目录时照同样的形状来：一份简短 README、一个可运行入口、一个会打印 pass/fail 的统计核对。
